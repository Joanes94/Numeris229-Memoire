\begin{abstract}
Chaque année, l'accès au code du numérique béninois reste difficile pour le citoyen comme pour l'étudiant. Cette situation est aggravée par l'existence de lois modificatrices, qui exposent tout lecteur du seul texte d'origine au risque de se fier à un article obsolète. Dans ce contexte, le présent travail propose la conception et l'implémentation d'un assistant conversationnel intelligent fondé sur une architecture RAG. La démarche retenue repose sur un pipeline d'ingestion documentaire reproductible, une indexation vectorielle dans ChromaDB avec le modèle d'embeddings Solon, un module de recherche combinant similarité sémantique et interrogation directe par référence d'article, ainsi qu'une architecture back-end modulaire exposée via une API REST, intégrant la gestion sécurisée des comptes utilisateurs. Le système garantit qu'aucune réponse n'est produite hors du périmètre du corpus indexé, limitant ainsi le risque d'hallucination. Les tests effectués démontrent la capacité du système à restituer des réponses précises et systématiquement sourcées à l'article, tant pour des questions formulées en langage naturel que pour des demandes portant sur un article précis.

\paragraph{}
\textbf{Mots clés}: RAG (Génération augmentée par récupération), code du numérique, architecture logicielle, droit numérique béninois, assistant conversationnel.
\end{abstract}

\begin{abstract}

Access to Benin's Digital Code remains difficult for citizens and students. This challenge is compounded by amending laws: readers consulting only the original text risk relying on outdated provisions. This work presents the design and implementation of an intelligent conversational assistant based on a retrieval-augmented generation (RAG) architecture. The approach uses a reproducible document-ingestion pipeline, vector indexing in ChromaDB with the Solon embedding model, and a retrieval module combining semantic similarity search with direct lookup by article reference. It also relies on a modular back end exposed through a REST API and includes secure user-account management. The system ensures that answers are generated only from the indexed corpus, thereby limiting hallucinations. Tests demonstrate its ability to provide accurate answers with systematic article-level citations, both to natural-language questions and to queries about a specific article.

\paragraph{}
\textbf{Key words}: RAG (Retrieval-Augmented Generation), Benin's Digital Code, software architecture, Beninese digital law, conversational assistant.
\end{abstract}
